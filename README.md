# 巡演舞台调度与走位编排工作台

面向剧院巡演团队的舞台执行工作台，覆盖演员与道具调度、舞台走位、执行提示、留言协同、版本回退、基线锁定和演出文档打印。

## 技术栈

Vue 3 + Element Plus + Pinia + Vue Router + TanStack Query + Axios + MSW + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62044`。

## 核心工作流

- 在舞台平面图中选择走位，编辑入场点、退场点、路线节点和触发时机。
- 在同一脚本时间线中维护灯光、音响、道具与执行提示。
- **提示发放流程（提示发放台 `/dispatch`）**
  - 提示先发放：发放时固定内容版本（v1），向应收回执部门下发确认任务；未发放提示（含无回执的旧数据）按「未发放」显示。
  - 时间、路线、执行部门、回执部门等内容一旦改版发布，版本号 +1，旧版本部门回执**全部作废**，提示回到「待确认」，旧回执留痕但不进入基线与打印。
  - 每个部门的回执按 `(提示, 版本, 部门)` 槽位生效：两岗同时提交同一槽位时**先到者生效**，后到者收到冲突提示并看到已生效版本（操作人、时间、序号）；同 clientId 补传按幂等只保留一次。
  - **演出基线**：当前版本应收回执未全部收齐的提示不能锁定基线，拦截清单逐条列出未发放 / 缺回执的部门。
  - **打印清单**：打印中心只输出版本收齐的提示；存在未收齐项时打印与 CSV 导出按钮禁用并给出拦截明细。
- **断网回执队列**
  - 断网期间的部门确认进入本地队列，同一「提示 + 部门」重复补传只留一条（以最新版本覆盖）。
  - 回网后先同步提示内容，再逐条合并回执；重复、失效回执由服务端归并。
  - 同步失败时原队列原样保留（失败条及之后全部不动），重试从第一条未确认项继续；可在发放台用「安排下次同步失败」演示。
- 添加部门留言、标记问题并生成修改版本；撤销、重做和离线草稿会自动保存。
- 锁定演出基线，并从打印中心输出走位表和执行清单。
